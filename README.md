# Лабораторная работа №3. Объектно-ориентированное программирование

## Описание

Структуры данных из ЛР1 и ЛР2 оформлены как классы на C++17 и Go: массив, односвязный и
двусвязный списки, стек, очередь, хеш-таблица, АВЛ-дерево. Общий абстрактный класс `Container`
(в Go — интерфейс), модульные тесты, покрытие, бенчмарки, сериализация в бинарный и текстовый
(JSON) формат, UML-диаграммы (`UML.md`).

## Задание

1. Реализовать классы с базовым набором операций (private, public) на основе ЛР1 и ЛР2 на C++ и Go: массив, список (односвязный, двусвязный), очередь, стек, хеш-таблица, дерево (АВЛ). Многофайловый проект, использование линтеров.
2. Реализовать покрытие тестами не менее 85 %, использовать бенчмарки:
   - C++: Boost Test Library, Google Test, Catch2 (`test_boost.cpp`, `test_gtest.cpp`, `test_catch2.cpp`), HTML-отчёт о покрытии;
   - Go: testing, testify (`structures_test.go`, `bench_test.go`), HTML-отчёт о покрытии.
3. Выполнить сериализацию и десериализацию данных бинарного и текстового форматов.
4. Представить UML-диаграммы классов.
5. Теоретическая часть (чётный вариант): анализ мировых практик оценки качества ПО (ISO 25010), основные виды тестирования.
